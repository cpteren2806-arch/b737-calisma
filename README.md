# B737 Study App ✈️

An Android app I made to study the **Boeing 737NG / 737 MAX** systems during my aircraft maintenance technician training.

It started as a simple notes-and-quiz app and slowly grew into an interactive 3D cockpit where you can flip switches, see what's behind the panels, and learn how each system works.

> 🚧 **Work in progress:** the app is still under development, so this is not the final version. Some features are incomplete and things may change or break.

> ⚠️ This is a student project for learning only. It is not an official manual and must not be used for real aircraft maintenance.

## What's inside

- Study notes for the main ATA chapters, with quizzes
- Interactive 3D cockpit panels with working switches and displays
- Wiring, connectors and circuit breakers behind the panels
- A simple system simulation (power up, APU, engine start)
- Guided scenarios that walk you through procedures step by step

## How to install

Download the latest APK from **Releases** and install it on your Android phone.
